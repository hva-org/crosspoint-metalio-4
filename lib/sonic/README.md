# Sonic

Bill Cox's Sonic library for changing speech speed without changing pitch,
copied unmodified from [waywardgeek/sonic](https://github.com/waywardgeek/sonic)
commit `b93885dcb70aae50c6f76b0fe4e0868f029a077e` (`sonic.c`, `sonic.h`).
Apache License 2.0; see `LICENSE`.

The `metalio_eink4-audiobook` environments (the EchoPoint firmware) build it,
and host tests compile it. Do not reformat these files.
